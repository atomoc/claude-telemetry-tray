Claude Telemetry Tray
=====================
Windows : double-click start-tray-windows.bat (first run), then -silent.bat for quiet start.
macOS/Linux : ./start-tray-mac-linux.sh   (auto-starts at login after install).
Open "Settings..." in the tray to set token, collector URL and the account filter.
The tray must stay running: telemetry always flows through its local proxy.
Full docs: https://github.com/<you>/claude-telemetry-tray
